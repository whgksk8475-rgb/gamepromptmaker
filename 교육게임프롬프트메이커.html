교육게임 프롬프트 메이커

게임 정보와 게이미피케이션 요소를 고르면 원하는 AI에 바로 붙여넣을 제작 프롬프트가 만들어집니다. 지금은 예시가 채워져 있습니다.

Gemini API 연결 먼저 키를 넣으면 다듬기·초안 기능을 쓸 수 있습니다 연결 안 됨

이 화면(Claude 아티팩트)은 보안상 외부 API 호출이 막혀 있어 Gemini 기능이 작동하지 않습니다. 배포용 HTML 파일을 GitHub Pages 같은 내 사이트에 올리면 작동합니다. 프롬프트 만들기와 복사는 여기서도 그대로 됩니다.

Google AI Studio에서 API 키 받기

  1. Google AI Studio 주소로 들어갑니다
    https://aistudio.google.com새 탭에서 열기
    주소창에 직접 입력하거나 복사해서 붙여넣으세요.
  2. 구글 계정으로 로그인합니다 처음 들어가면 이용약관 동의 창이 나옵니다. 동의하고 계속합니다. 학교에서 받은 교육용 구글 계정은 관리자가 막아 둔 경우가 많아 개인 구글 계정을 권합니다.
  3. 왼쪽 아래(또는 위쪽 메뉴)의 Get API key를 누릅니다 메뉴가 안 보이면 아래 주소로 바로 들어가도 됩니다.
    https://aistudio.google.com/apikey새 탭에서 열기
  4. Create API key(API 키 만들기)를 누릅니다 프로젝트를 고르라고 하면 기본으로 나오는 프로젝트를 그대로 쓰거나 새로 만듭니다. 결제 정보 없이 무료 등급으로 쓸 수 있습니다.
  5. 만들어진 키를 복사합니다 AIza로 시작하는 39자 정도의 문자열입니다. 키 옆의 복사 아이콘을 누르면 됩니다.
  6. 이 페이지의 'API 키' 칸에 붙여넣습니다 오른쪽 위 표시가 '키 입력됨'으로 바뀌면 준비 끝입니다. 아래 '모델 목록 불러오기'를 눌러 연결이 되는지 확인해 보세요.

주의할 점: 키는 비밀번호처럼 다룹니다. 다른 사람에게 보내거나 수업 자료·화면 공유에 노출하지 마세요. 노출됐다면 같은 화면에서 키를 삭제하고 새로 만들면 됩니다. 무료 등급은 분당·하루 사용량 한도가 있어, 한도에 걸리면 잠시 뒤 다시 시도하면 됩니다.

무료는 결제 등록 없이 바로 쓸 수 있지만 사용량 한도가 있고, 입력한 내용이 구글 서비스 개선에 쓰일 수 있습니다. 유료는 AI Studio에서 결제 정보를 등록해야 작동합니다. 학생 개인정보는 넣지 마세요. (2026년 10월 Gemini API 요금표 기준)
